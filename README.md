# Empanadas La Económica

Sistema web para la gestión de productos, usuarios y compras de Empanadas La Económica.

## Tecnologías

- HTML
- CSS
- PHP
- MySQL
- Git
- GitHub

## Funcionalidades

- Registro de usuarios
- Inicio de sesión
- Gestión de productos
- Realización de compras
- Historial de compras
- Administración del sistema
